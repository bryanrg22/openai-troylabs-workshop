# Workshop brand assets

These assets support the OpenAI Student Collective × TroyLabs workshop at USC. They identify the collaboration and campus context, not a separate product endorsement. Brand owners retain rights to their marks.

## Sources

- **`student-collective-globe.png`** — the organizer’s uploaded red/gold globe, supplied as `image(20261020-034812).png`. Preserved unchanged. This is workshop artwork, not a claim that it is an official Student Collective logo.
- **`openai-workshop-art.png`** — the organizer’s uploaded OpenAI artwork, supplied as `image(20261020-034821).png`. Preserved unchanged.
- **Student Collective name** — verified against [OpenAI’s official Student Collective page](https://openai.com/student-collective/). The brand strip uses the program name as live SVG text beside the supplied OpenAI artwork; it is a workshop composition, not an official program lockup.
- **`troylabs-mark.svg`** — the white rocket mark extracted unchanged from the navigation link labeled “TroyLabs home” on [the official TroyLabs website](https://usctroylabs.com/). The brand strip displays that mark on cardinal, with a separate TroyLabs text label.
- **`usc-primary-logotype.png`** — the primary logotype displayed on [USC’s official marks and logotypes page](https://identity.usc.edu/identity/logos-marks/), downloaded from [this official PNG](https://identity.usc.edu/wp-content/uploads/2022/08/PrimaryLogotype-1024x219.png). Displayed proportionally on white with surrounding clear space; no recoloring or redrawing.

Sources checked October 19, 2026.

## README display

- **`workshop-header.svg`** — 1280 × 440, displayed at up to 960 px wide. Combines the supplied globe with accessible workshop title text on cardinal.
- **`workshop-brands.svg`** — 1280 × 160, displayed at up to 960 px wide. Uses a fixed white background so the USC and TroyLabs marks remain legible in light and dark GitHub themes.

Both compositions embed their image data, use no scripts, fonts, or external image requests, and preserve the source artwork’s aspect ratios. The README supplies descriptive alternative text and repeats the essential title, date, and links as selectable text. All displayed assets are hosted in this repository.
