# OpenAI Student Collective × TroyLabs

## Shipping Your First Agent

**LaunchDesk** is a fictional customer support startup used in our hands-on workshop. Students inherit an existing MVP and use Codex to integrate an AI customer support agent, design the backend, and connect local SQLite order and ticket data.

### Workshop plan

1. Inspect the existing MVP and discuss system design.
2. Use Codex to implement the AI support agent.
3. Connect tools for order lookup and ticket creation.
4. Test, debug, and discuss production deployment.

The complete prepared starter project includes the local application, mock customers and orders, company handbook, database schema, and Codex workshop instructions. Those files still need to be uploaded to this repository.
